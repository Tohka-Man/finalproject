Нужно:
Т1 - вопрос-ответ-id
Т2 - вопрос(от пользователя)-специалист из таблицы специалистов(FK)-id
Т3 - специалисты-наименование-описание-id

Бот, стартовые команды:

/question - вывод всех базовых вопросовиз таблицы Т1 (/q1 - вопрос1 и тд)
/special - если не нашли нужный вопрос можем перенаправить к специалисту
