Бот проработан для базового использования. Основные функции созданы, такие как:
/start - вывод стартовых команд
/question - вывод всех базовых вопросов (/q1 - ответ на вопрос1 и тд)
/special - если не нашли нужный вопрос можем перенаправить к специалисту

Бот имеет интуитивно-понятное управление, с которым справится каждый
